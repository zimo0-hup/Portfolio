Site-to-Site IPsec VPN

GNS3 · Cisco IOS · HQ ↔ Branch over ISP

Built a secure IPsec tunnel linking HQ (10.0.10.0/24) and Branch (10.0.20.0/24) across a simulated ISP, using AES-256 encryption with SHA HMAC integrity. Configured PAT for Internet access with NAT exemption so VPN-bound traffic bypasses translation, and verified the tunnel with show commands.

Security notes: Tunnel-mode ESP with AES-256. The lab runs an IOS 12.4 (IKEv1-era) image, which limits the options. In production I would use IKEv2 with SHA-256 or higher, DH group 14+, PFS, short SA lifetimes, strong keys or certificates, and an ACL restricting allowed VPN peers.
